## STEP 1｜GitHub にプライベートリポジトリを作る → ✅ 完了（2026-10-18）

- リポジトリ：**https://github.com/rasoltekaworu369-art/threads-auto-post**（Private・確認済み）
- 24ファイルを push 済み。ローカルとリモートのコミットは一致。
- Actions のワークフロー3本（自動投稿 / 計測 / トークン更新）が **active** で登録済み。
- 改行コードは全スクリプト・全ワークフローで LF（Ubuntu で落ちない）。

> **詰まった点の記録：** 認証前の push が「Repository not found」で落ちた。
> GitHub はプライベートリポジトリに未認証でアクセスされると、存在を漏らさないために 401 ではなく **404** を返す。
> そのため git は「認証が必要」と気づけず、パスワードを聞かずに終わる。
> **プライベートリポジトリの 404 は、まず認証を疑う。** 認証後も 404 なら、そのときは本当に名前が違う。

## STEP 2｜Meta アプリを作って Threads のトークンを取る

→ **詳細は `運用/Metaアプリとトークン取得.md` に分けた。** 認可URLの組み立て、リダイレクトURIの選び方、
エラーの対応表、ホストの話まで入っている。要点だけ：

- アプリ作成時のユースケースは **Threads** を選ぶ。**Threads 用の App ID / App Secret を使う**（Meta が同時に作る別系統のものでは動かない）
- **自分を Threads テスターとして招待し、Threads 側で承諾する** → これで **App Review は不要**

- 認可コード（1時間・使い捨て）→ 短期トークン（1時間）→ **長期トークン（60日）** まで必ず進める
- 🔴 **リダイレクトURIに他人のサイトを登録しない。** 認可コードがその相手のサーバーに飛ぶ

## STEP 5｜Routine A と C を作る

https://claude.ai/code/routines → **New routine**

| | Routine A | Routine C |
|---|---|---|
| 名前 | Threads 翌日分9本の生成 | Threads 反応の判定と改善案 |
| プロンプト | `運用/Routine_A_生成プロンプト.md` の中身をそのまま貼る | `運用/Routine_C_計測改善プロンプト.md` |
| リポジトリ | `threads-auto-post` | `threads-auto-post` |
| 環境 | **Default のまま**（外部APIを呼ばないので許可ドメイン変更は不要） | Default のまま |
| コネクタ | **全部外す** | 全部外す |
| スケジュール | daily を選んで時刻 **23:07** | daily を選んで時刻 **05:07** |
| モデル | 一番強いものを選ぶ | 標準でよい |

- 時刻は**ローカルタイムで入る**。毎時ピッタリは数分遅れるので :07 にしてある
- **2時間おきの投稿は Routine ではなく GitHub Actions がやる**（Routine の最小間隔は1時間で、9回/日の Claude セッションは使用量の無駄）

### 作ったら、まず Run now

自動スケジュールに乗せる前に、Routine A を **Run now** で手動実行して、できた9本を目で見る。
型が9本ぜんぶ違うか、締めが質問/言い切り/労いに3本ずつ割れているかを確認する。

## 走り出したあとの確認ポイント

| いつ | 見るもの | 異常のサイン |
|---|---|---|
| 毎朝 | `queue/<今日>.json` が9件あるか | 無い → Routine A が失敗。claude.ai/code/routines で run のログを読む |
| 毎朝 | `posted/<昨日>.json` が9件あるか | 少ない → Actions の失敗。Actions タブのログを読む |
| 毎週 | 「Threads トークン更新」が緑か | 赤 → 🔴 最優先で対処。放置すると60日で全停止 |
| 2週間後 | `reaction-log.csv` の clicks | TOP3の合計が1日20未満 → 仕組みより先に「入れ物」の問題が残っている |

GitHub の接続が切れると Routine は最大72時間スキップし、それを超えると自動 OFF になる（復帰は手動）。
