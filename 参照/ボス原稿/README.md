# ボス原稿の置き場（言い換え在庫の出典）

> 🔴 **ここに置いてよいのは、ボス本人の言葉だけ。** 呪術者（AI）が書いた下書きは置かない。
> AI文を出典にすると、AI文が在庫に戻ってきて再循環する（`scripts/harvest_phrasings.py` の注記）。

## 置くもの

| 種類 | ファイル名の例 | 備考 |
|---|---|---|
| スピの原稿（note・投稿・下書き） | `2026-10-21_原稿_神の天秤.md` | ボスが書いた or 推敲したもの |
| 🎙 週末の音声メモの文字起こし | `2026-10-25_音声_お金の不安.txt` | スマホの文字起こしをそのまま貼ってよい。**直さなくてよい**（言い淀みは採取器が文の長さで落とす） |

- 1ファイル1テーマでも、まとめて1ファイルでもよい
- 恋愛・AI副業の原稿を置いても、採取器が中身で判定してスピ以外は落とす
- 🔴 **有料部分（重りの正体・降ろし方・診断21問・台本・30日実行表）の文は採取器が自動で落とす**が、気になるものは最初から置かない

## 置いたあと

`python3 scripts/harvest_phrasings.py` を実行すると、`参照/言い換え在庫_スピ.md` に `要変換` の行が増える。
Routine A は在庫の `使える` が3行未満のときに自分でこれを実行する（手順書の禁止事項）ので、**ボスは置くだけでよい。**

## 音声メモ → note記事 との兼用

土日に録る音声は、note記事の素材と兼用できる。**文字起こしの原文**をここに置き、記事はそこから別に作る。
記事にした後の推敲済み原稿も、ここに追加で置いてよい（同じ話でも言い方が変わっていれば別の在庫になる）。
