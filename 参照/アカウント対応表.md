## 4. 時刻(ぶつけない)

| 仕事 | `spi` | `renai` | 理由 |
|---|---|---|---|
| **Routine A(生成)** | 23:07 | 🆕 **23:47** | 🔴 同時刻だと push がぶつかる。スピの後ろに置く |
| **Routine C(計測改善)** | 05:07 | 🆕 **05:47** | 同上 |
| post(投稿) | 2時間おき9枠(06〜22時の各00〜30分) | **同じ枠** | ⚠️ 1回の実行で spi → renai の順に**直列**で回る(`max-parallel: 1`) |
| insights(計測) | 04:07 | 同じ便 | 同上 |
| replies(読者の返信) | 22:20 | 同じ便 | 🔴 Routine A より前に揃っている必要がある |
| refresh-token | 毎週日曜 03:07 | 同じ便 | 🔴 **アカウントごとに別のトークン。両方を更新する** |

## 6. 新しいアカウントを足すときに触る場所(全部で5つ)

1. **この表**(§1〜§5に行を足す)
2. `scripts/acct_env.sh` の `case` に1ブロック足す
3. 5つのワークフローの `matrix.include` に1件足す
4. `<新PFX>/` に骨組みを置く(`concept.md` / `improve.md` / `reaction-log.csv` / `本数.txt` / `queue/` / `posted/` / `直近の型.md`)
5. `参照/` にジャンル専用の4点を置く(お手本・オリジン在庫・言い換え在庫・ボス原稿フォルダ)

🔴 **これ以外の場所を触る必要が出たら、それは設計が崩れている合図。** 増やす前に晴明を呼ぶこと。
