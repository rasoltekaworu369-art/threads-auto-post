## 0. なぜこうなったか（診断・実測）

呪術者が文体憲章を「チェックリスト」として使い、**毎回同じ順に全項目を埋めていた**のが原因。

実測（直近の原稿群での出現本数）:

| 反復しているもの | 出現 |
|---|---|
| 「では、今回は以上です」 | 7本 |
| 「どうも、ジン・カヲルです」 | 7本 |
| 「※これ『◯◯』ってやつですね」 | 7本 |
| 「灰色文章（グレーテキスト）」 | 6本 |
| 「3ヶ月後の話も、しておきますね」 | 6本 |
| 「反射的に半歩引くタイプですので」 | 5本（ほぼ一字一句同じ） |
| 「音声だけの教材で8桁」 | 5本 |
| 「半年つまずいた／溶かした」 | 10本 |

構成も毎回この11手だった:
シーン → 命名 → 名乗り → リフレーム → ※正式名称 → 手順 → つまずき＋回避策 → 3ヶ月後の未来 → 今日やること1つ → 突き放し → 署名 → ★追伸

**憲章の条項は「満たすべき機能」であって「並べる順番」ではない。**
同じ機能は、違う順番・違う形でも満たせる。それを取り違えていた。

> 憲章「採点の校正値」:チェックリストは減点法の下限テストであって、上限の証明ではない。
> 技術大全§7-1:型を見せるな、効かせろ。型が見えた時点で敗北。

## 1. 運用ルール（これを守る）

1. **執筆前にこのファイルを読み、末尾の台帳を見る。**
2. **直近3本で使った「構成の型」「開幕の型」「締めの型」「命名の製法」は選ばない。**
3. **固定フレーズは3本に1回まで。**（下の§7「使用制限フレーズ」参照）
4. **オリジンは1本につき1〜2断片だけ。**全部盛りにしない（§6）。
5. 書き終えたら**台帳に記録する。**記録しないと次回また同じ型を引く。
6. ⚠️ ゲート項目（E0ターゲット整合／L1当事者化）は**型を変えても必ず満たす。**これは順番ではなく機能なので、どの型でも実装できる。

## 2. 構成の型（記事の骨格）10種

### A【診断型】※現行の標準・使いすぎ
シーン → 命名 → 原因 → 見分け方 → 手順 → 今日の1手 → 追伸
向く題材:読者が「自分がどこで詰まっているか分からない」とき

### B【一問一答型】
見出しを全部「読者の質問」にする。命名は最後に1つだけ置くか、置かない。
例:「Q. 毎日書いたほうがいいですか」「Q. AIに書かせるとバレませんか」
向く題材:反論が多いテーマ／既に知識がある読者
効き方:E12（見出しを読者の疑問文にする）の全面適用。手順書に見えないのが利点

### C【失敗告白型】
自分の失敗を時系列で最後まで語り切る。**手順を書かない。**教訓は最後に1つだけ。
向く題材:読者が既にやり方を知っていて、動けていないとき
効き方:P12（有料の価値は手順表に載らない実感）の記事版。読者は手順でなく体験に動かされる

### D【裁判型】
対立する2説を並べて検証し、最後に判決を出す。
例:「毎日更新は正しいのか、間違っているのか」を両側から検証する
向く題材:世間で意見が割れているテーマ
効き方:読者は「答え」より「検証の過程」に信頼を置く。E6リフレームを演繹の形で見せられる

### E【実験レポート型】
「試しに◯◯してみた」。**結果を先に出してから、過程を語る。**
向く題材:検証可能なやり方（AIに投げる系は全部これで書ける）
効き方:証拠が構成そのものになる。売り込み臭が最小

### F【手紙型】
特定の1人に宛てて書く（過去の自分／相談してきた人／3ヶ月前に辞めた人）。読者は"盗み読む"形になる。
向く題材:情緒で動かすテーマ／CTAを置きたくない記事
効き方:L6（あなたの密度）を極限まで上げられる。ただし手紙形式なので手順は書けない

### G【解体型】
世間の定説を3〜5個並べ、1つずつ潰していく。**命名しない。**リズムで押す。
向く題材:市場が成熟していて、読者が「もう知っている」と思っているテーマ
効き方:S5ランキング型の長文版。「そして最後の1つは、、」で落とす

### H【一日追体験型】
読者の1日／1週間を時間軸で追い、手順を時間の中に埋め込む。
例:「月曜の夜」「水曜の帰り道」「日曜の午前」
向く題材:習慣・継続がテーマのとき
効き方:手順が「やること」でなく「生活」に見える。読者の負荷が下がる

### I【対話型】
自分の中の反対者と議論する。「いや、それは違うだろ」と自分に言わせる。
向く題材:自分の主張が強すぎて、押し付けに見えそうなとき
効き方:E2仮想対話の最上級。反論処理が構成そのものになる

### J【逆算型】
結果（未来のシーン）から書き始めて、そこへ至る道を遡る。
向く題材:読者が「そこまで行けるとは思っていない」とき
効き方:E10（未来は引用セリフ入りのシーンで描く）を冒頭に持ってくる形

### K【現在地告白型】🆕 2026-09-19 新設(部室音声 第9回)
自分の**"今"の状態**を、時系列ではなく断面で語り切る → 世間との対比で反転させる → 読者を格上げして終わる。**手順を書かない。**
向く題材:読者が「こうなっているのは自分だけなのか」と思っているとき
**C【失敗告白型】との違い:C は過去形・克服済み。K は現在形・克服していない。**
効き方:憲章 L14(弱点を過去形にしない)/ L37(弱点の現在形告白は芯の語で書く)が、そのまま構成の骨格になった型。**書き手が"まだ同じ場所にいる"ので、最後の格上げが上から目線にならない**
⚠️ **素材の条件が厳しい。**書き手に「今も続いている不利な事実」が無いと成立しない。持っていない題材では選ばないこと

## 3. 開幕の型 8種（全部ゲート20＝当事者化を満たす）

⚠️ L1の「状況を「」で提示 → 名指しの問い → 推量＋同意要求」は**3段の"形"ではなく"当事者にする"という機能。**下のどれでも満たせる。

1. **状況カード＋問い**（現行標準・使いすぎ）
   「note3年目。」→「今、あなたのダッシュボードは〜？」
2. **読者の内心セリフ1行から**
   「"まあ、明日でいいか"」→「この一言、今月何回言いましたか？」
3. **数字1つから**
   「47。」→「これ、何の数字か分かりますか。あなたの先週のビュー数かもしれません」
4. **否定から**
   「今日は、よく言われている"アレ"を一度疑ってみます」
5. **自分の失敗の一撃から**（オリジンを冒頭に前倒し）
   「私は、これを知らずに1年ぶんの原稿を捨てました」
6. **二者択一を突きつける**（S19-1）
   「あなたは"上手い文章"を書きたいですか。それとも"読まれる文章"ですか」
7. **命令形1行**（S19-2）
   「毎日更新は、するな。」→ 本文はです・ますに戻す
8. **問いだけを置く**
   「最後に記事を"公開"したのは、いつでしたか。」

## 4. 締めの型 8種

1. **「では、今回は以上です」＋署名**（使いすぎ・7本。しばらく封印）
2. **号令型**「一緒に◯◯を始めましょう」（E12）
3. **未来の断定**（S19-12）「大丈夫です、ここまで読んでいるなら、あなたが◯◯になるのは必然なので」
4. **引き受ける締め**（S16-16）読者に宿題を増やさず、自分が引き受けて終わる
5. **読者を格上げし、標的を世間へ**（P14-3）「あなたはもう◯◯です。その辺の△△とは格が違います」
6. **時代への接続**（L9）「令和は、こういう人が選ばれることが多いんですね」
7. **短い一撃で終える**（説明せず、単独行＋署名だけ）
8. **私信を追伸に置く**（S20-9）読者に向けていない文章を最後に置く

## 5. 命名の製法 6種

1. **状態への皮肉な日常語**（無観客ライブ／祈り待ち）※使いすぎ
2. **人への命名**（脳内作家／祈り人）※P40。使用済み
3. **痛い等式**（S15-b-3）『お金の大小＝自分の存在価値』
4. **既存の言葉を"言い訳"と名指す**（S16-4）「『男は中身で勝負』という言い訳」
5. **行為への命名**（一人恋愛反省会／ダッシュボード巡回）
6. **命名しない**（G解体型など、型が見えそうなときは、あえて名前を付けない）

⚠️ **命名は1本に1つ。**そして**5本連続で同じ製法を使わない。**

## 5-b. タイトルの型（2026-09-05 新設・ボスが呪術者の推し案を全没にした実測から）

⚠️ **どの型でも共通の絶対ルール（P46）：自作の命名をタイトルに乗せない。**
症状側でも解決策側でも同じ。乗せていいのは**読者が既に使っている語と、読者が検索する語**（例：「AI副業」）だけ。

| # | 型 | 骨格 | 実例 |
|---|---|---|---|
| T1 | **読者選別（排除）** | 「〇年以上〜な人だけ読んでください」 | 10年以上「貧乏」でお金が寄ってこない…（売れた） |
| T2 | **宛名（差し出し）** | 「〜あなたのために書いた記事。」 | 5年以上「嫌われないように〜」あなたのために |
| T3 | **症状の名指し＋未来を閉じる** | 「〜と言う人ほど、いつまでも〜できません」 | 本数で埋めるのをやめられない人ほど… |
| T4 | **問い** | 「〜を思い出せますか」 | 3ヶ月前に書いたnote、あなたは"誰に宛てて"… |
| **T5** | **🆕 資格の付与（2026-09-05）** | **「あなたが〈読者がもう経験している事実〉があれば、あなたは〈欲しい立場〉が向いています」** | **あなたがAIを使って「便利だな」と思った経験があれば、あなたは"AI副業"が向いています** |

**T5の設計規則（ボス実物から）**
- 条件節に置くのは、**読者が既に済ませていること**。だから全員が通る
- 帰結節に置くのは、**資格の認定**（脅しではなく認める）
- **「あなた」を条件節と帰結節の両方に入れる**
- ⚠️ **T5では L28（後半に解決策の固有名＋持ち帰りを足す）を適用しない。**適用すると自作命名が乗ってP46違反になる
- 無料の集客記事向き。**T3（未来を閉じる）の裏返し**なので、連続で使わず交互に出す

**T6【告白】🆕 2026-09-19 新設(部室音声 第9回)**
> 骨格:**書き手の"今"の不利な事実を、そのままタイトルに置く。**
> 実例:**「私にも今、彼女はいません」**(恋愛コンサル歴12年の書き手が言う)
- ①**必ず現在形。**過去形にすると「今は違う=自慢」に反転する(L14)
- ②**読者が既に使っている語だけで組む**(P46)。この例は「彼女」「いません」だけ
- ③**権威と正面から矛盾する事実を選ぶ。**矛盾が大きいほど、読者の警戒(「どうせこの人は◯◯側だろ」)を1行で潰せる
- ⚠️ **連続では使えない。**2回目からは「またか」になる。**間を3本以上あける**

## 6. オリジン断片の在庫（1本につき1〜2断片だけ）

全部盛りにしない。**毎回「13年＋音声8桁＋WordPress崩壊」を並べていたのが、いちばん既視感を生んでいた。**

| 断片 | 直近の使用 | 状態 |
|---|---|---|
| WordPress崩壊・収入0円 | 多数 | 🔴 使いすぎ。しばらく休ませる |
| 音声教材で8桁 | 5本 | 🔴 使いすぎ |
| ライティング13年 | ほぼ全部 | 🟡 権威として必要だが、毎回冒頭に置かない |
| 書けなくなった（強い言葉を捨てた） | 3本 | 🟢 まだ使える |
| 直すべきは文章でなくネタだと気づくのに半年 | 10本 | 🔴 「半年」が使いすぎ |
| 恋愛ジャンル13年 | 数本 | 🟢 |
| 個別コンサル50万円（価格アンカー用） | 1本 | 🟢 未活用。E11-7で使える |
| 教材2〜3万円／コンサル販売の経験 | 0本 | 🟢 未活用 |

⚠️ **ボスの実体験で未使用の断片があれば、ここに追加してもらう。**呪術者が創作すると削られる領域（P20）なので、在庫が増えるほど反復が減る。

## 7. 使用制限フレーズ（3本に1回まで）

以下は「ボスの指紋」だが、**連続で使うと指紋ではなく癖になる。**

- 「どうも、ジン・カヲルです」→ 名乗りの位置と形を変える（「あ、どうもジン・カヲルです」／名乗らない回があってもいい）
- 「また実績アピールか、と思いますよね」
- 「反射的に半歩引くタイプですので」
- 「※これ『◯◯』ってやつですね」
- 「3ヶ月後の話も、しておきますね」
- 「今日やることは、1つだけです」
- 「ただ、最後に1つだけ、突き放したことを言っておきます」
- 「では、今回は以上です。最後まで読んでいただき、ありがとうございました。」
- 「灰色文章（グレーテキスト）」← 商品の看板用語なので、記事の主題でないときは使わない
- 「〜ので。」← P19のボス最大の癖だが、1本に15回以上入れると単調になる。**10回前後を目安に**
