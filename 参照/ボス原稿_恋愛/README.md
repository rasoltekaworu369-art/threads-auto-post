# ボス原稿の置き場・恋愛（言い換え在庫の出典）

> 🔴 **ここに置いてよいのは、ボス本人の言葉だけ。** 呪術者（AI）が書いた下書きは置かない。
> AI文を出典にすると、AI文が在庫に戻ってきて再循環する（`scripts/harvest_phrasings.py` の注記）。

## 置くもの

| 種類 | ファイル名の例 | 備考 |
|---|---|---|
| 恋愛の原稿（note・投稿・下書き） | `2026-11-02_原稿_本命の前で頭が真っ白.md` | ボスが書いた or 推敲したもの |
| 🎙 部室音声の文字起こし | `2026-11-01_音声_部室第15回.txt` | スマホの文字起こしをそのまま貼ってよい。**直さなくてよい** |

- スピ・AI副業の原稿を置いても、採取器が中身で判定して恋愛以外は落とす
- 🔴 **有料部分（台本・ワーク・診断の答え）の文は、気になるものは最初から置かない**

## 置いたあと

`ACCT=renai python3 scripts/harvest_phrasings.py` を実行すると、`参照/言い換え在庫_恋愛.md` に `要変換` の行が増える。
Routine A（恋愛）は在庫の `使える` が3行未満のときに自分でこれを実行するので、**ボスは置くだけでよい。**
